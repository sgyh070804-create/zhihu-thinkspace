# 刘看山参考重建模型 · 第一轮网格版

依据用户提供的 `kanshan_material.zip` 中正面、侧面、背面三视图和三分之四视角照片重建。该文件是实际三维网格资产，不是角色图片、平面贴片或网页里拼接的球体模型。

## 文件

- `kanshan-source.blend`：可编辑 Blender 4.5 工程，包含角色、控制网格、11 根变形骨骼、材质、灯光、4 台正交相机及打包的原始三视图。
- `kanshan-reference-model.glb`：8 个网格、131,680 个导出顶点、263,328 个三角面、11 根骨骼。可用于 Three.js / Blender / 其他 glTF 工具。
- `render-front/side/back/hero.png`：实际 Blender Cycles 渲染。
- `build_kanshan.py`：实际生成和细修模型的 Blender Python 源码，可调整截面、轮廓与绑定。
- `mesh-validation.json`：Blender 中逐网格检查结果。
- `preview.html`：加载真实 GLB 的旋转、正侧背视图、线框、骨骼检查器。

## 建模内容

头和躯干由连续截面放样形成一体网格；耳根与尾巴经体素焊接和平滑过渡，原始控制网格保存在隐藏集合 `EDITABLE_Control_Cages` 中。口鼻前伸量根据侧视轮廓设置，鼻头、眼睛为独立材质网格。手臂使用曲线截面放样，手掌与三根手指和拇指焊接为一体；腿与脚掌连续连接。

第一轮渲染中发现的横向曲面条带已通过连续导数插值修正，并重新渲染。所有 8 个角色网格检查均为 0 开边、0 非流形边。骨骼包含身体、头、双侧上臂/前臂/手、双腿及根骨骼。

## 查看

在此目录运行 `python -m http.server 8781 --bind 127.0.0.1`，打开 `http://127.0.0.1:8781/preview.html`。

浏览器已经实际验证：GLB 独立载入、侧面、背面、线框与骨骼切换；未捕获 console error/warn。

## 当前边界

这是从有限二维参考重建的模型，不是官方原始网格，不能声称与官方资产 100% 一致。轮廓比例以三视图为准；耳根曲率、指尖形状和鼻部曲面仍有重建误差，尚未经用户外形验收。当前为静态基础绑定，没有制作讨论动作库、面部表情系统、UV 绘制或手工动画拓扑重排；导出的高面数网格也尚未进行多人场景性能优化。Blender 的程序微表面材质在 GLB 中以基础 PBR 材质表达。

## 讨论室接入版

运行时轻量 GLB 位于 `packages/debate-room/assets/kanshan/kanshan-runtime.glb`，从本原件减面导出，骨骼和外形比例保持。本目录保留高精度原件、可编辑压缩工程、参考与渲染。前端资源包还包含黑白气泡和冷灰蓝主题。
