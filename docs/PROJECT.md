# ThinkSpace 项目计划

更新：2026-11-12。当前处于立项阶段，功能尚未实现。后续源码、文档和进度以此仓库为准。

## 定位
AI 阅读思考助手与个人收藏知识库：收藏问答、拓展视角、观点沉淀。

## MVP
1. 知乎 OAuth 登录，选择并同步收藏夹。
2. 在指定收藏夹内问答，展示原文片段与来源。
3. 拆解帖子主张、论据、隐含前提，结合知乎和全网检索提供其他解释与反例。
4. 用户确认后保存观点、依据和修改历史。

## 暂定技术栈
- Web：Vue 3、TypeScript、Vite、Element Plus，适配手机。
- 服务端：Python、FastAPI、Pydantic、httpx、SSE。
- 存储：PostgreSQL、Qdrant。
- RAG：BGE-M3、BM25，可选 bge-reranker-v2-m3。
- 生成：独立封装千问 API；知乎直答用于公共资料问答。
- 部署：Docker Compose、Nginx。

## 官方接口
https://developer.zhihu.com/
https://www.zhihu.com/hackathon

计划接入 OAuth、收藏夹列表及内容、知乎搜索、全网搜索、直答。权限、额度、全文字段、分页和鉴权以参赛文档及实测为准；点赞历史接口尚待确认。

## 实现约束
- 检索必须按用户与收藏夹过滤。
- 收藏不等于认同；个人观点由用户确认。
- 区分收藏与外部资料来源，资料不足时明确说明。
- 密钥、OAuth token、真实用户数据不得提交到 Git。
