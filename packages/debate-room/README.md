# ThinkSpace 长桌讨论室 · 0.2.3

三位刘看山与用户同桌的前端讨论组件。当前版已接入用户确认的三维网格，使用原模型骨骼驱动头、身体、上臂、前臂和手；整体为冷灰蓝主题，角色气泡白底黑字，用户气泡黑底白字。

## 0.2.3 正式讨论的收手姿态

正式讨论默认自然垂手，位于桌面后方和桌面以下。倾听、点头、思考和暂停时手放下；发言只在开头短暂抬手强调，随后平滑收回。完整举手等动作仍可在动作试演中持续检查。

不再自动播放没有桌面接触的待机写字、举杯；笔和手持杯仅在试演中显示。本版采用自然垂手作为休息姿态，没有实现手掌或笔尖对桌面的接触解算。

正式接入请保留 `scene.js` 与 `motion-policy.mjs` 的收手调度，调用 `setSpeaker` 时重置发言动作时间，并通过 `setPaused` 同步暂停。不要把试演的循环姿态直接作为讨论待机。呼吸、头部动作和肘部外侧约束保留。

## 0.2.2 手肘方向修正

改用双骨骼实时解算，为左右肘分别设置随身体转动的外侧方向约束，修正抬手时向内折肘。优先保持原动作的手部目标和臂长；接近完全伸直时保留微小弯曲，避免弯曲方向翻转。输入姿态仍由弹簧连续过渡。

新增自动检查覆盖 12 种动作及切换过程，验证双肘始终在肩—腕连线外侧，且上臂、前臂长度不变。关闭修复后，该检查能复现举手动作左肘内折。

## 0.2.1 动作修正

为实际模型重新定义肩、肘、头和身体的动作目标，移除二次幅度衰减。手势越过桌面，挥手保持在头部轮廓外；点头、摇头、解释和展开的节奏与幅度分别校准。动作仍由连续弹簧和骨骼实时计算。

修复可见页面低帧率时将每帧截为 34ms 导致的慢动作；弹簧内部按不超过 8ms 的步长积分。隐藏页恢复时重置时间，长卡顿最多计入 1.05 秒。减少动态效果偏好下仍可平滑到达所选姿势。

动作试演选择后平滑拉近所选角色，关闭后回到全桌；普通讨论保持全景。试演期间隐藏头顶标签和发言，避免遮住动作。

## 运行

在本目录运行 `python -m http.server 8780 --bind 127.0.0.1`，打开 http://127.0.0.1:8780/index.html 。通过 HTTP 加载，不直接双击 HTML。

Three.js、GLTFLoader、SkeletonUtils 与 GLB 均已随包提供，不依赖 CDN，不需要安装运行依赖。

## 资源

- `assets/kanshan/kanshan-runtime.glb`：2.30 MB 的减面运行版，7 个网格、11 根骨骼、41,122 顶点、81,942 三角面。三位角色共享几何和材质，各自克隆独立骨骼。
- `assets/kanshan/asset-info.json`：运行资源规格。
- 仓库 [`assets/kanshan`](../../assets/kanshan)：压缩 Blender 可编辑原件、高精度 GLB、三视图、建模和减面源码、实际渲染与模型检查器。
- 仓库 `releases/thinkspace-resources-v0.2.3.zip`：前端、完整素材、文档与验证截图组成的可下载资源包。

模型载入后才启动讨论与动画预热；资源失败会显示错误。角色动作使用阻尼弹簧连续过渡，映射到实际骨骼。12 个动作入口、暂停/速度/重新开始、三个示例话题、用户输入、角色邀请、记录及 Markdown 导出保留。角色外形按用户参考图重建，当前资源已获用户确认，并非官方生产原模。

## 接入

`scene.js` 管理场景，`kanshan-character.js` 载入/克隆模型并绑定骨骼，`engine.mjs` 管理讨论，`app.js` 管理气泡和输入。`paper-character.js` 为旧版留档，当前入口不使用它。

```js
window.debateRoom.setTopic(1);
window.debateRoom.submit('我的观点');
window.debateRoom.pause();
window.debateRoom.resume();
window.debateRoom.getTranscript();
window.debateRoom.dispose();
```

本版仍是前端预设讨论，不会理解用户输入，没有真实 AI、OAuth、后端或多人联网同步。业务接入时替换讨论数据源即可。
